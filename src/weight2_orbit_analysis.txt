single-bit outputs (ADDITIVE = no interaction), or differ (NON-ADDITIVE = interaction)?

================================================================================
KEY FINDINGS
================================================================================

1. The 6 velocity cycles are period-2 transpositions under the stream step:
      (0,3), (1,2), (4,7), (5,6), (8,11), (9,10)
   Channels in the same cycle never collide (they swap positions each timestep).
   Weight-2 collisions only occur for bits from DIFFERENT velocity cycles.

2. Orbit classification by interaction type:
   O_0 (ch0,ch1, dot=+0): cross-cycle, |Stab|=4, ADDITIVE
   O_1 (ch1,ch2, dot=-2): same-cycle, |Stab|=8, ADDITIVE
   O_2 (ch0,ch4, dot=+1): cross-cycle, |Stab|=2, NON-ADDITIVE (interacting)
   O_3 (ch2,ch4, dot=-1): cross-cycle, |Stab|=2, NON-ADDITIVE (interacting)

3. Only cross-cycle weight-2 states can produce genuine two-body interactions.
   Same-cycle pairs can never co-occupy a cell (they swap positions).

4. The LUT-08 glider uses only channels in cycle (5,6). Since the 4 bits are
   all in the same velocity cycle, they never collide with each other,
   confirming LUT-08 as a non-interacting composite of 4 independent bits.
