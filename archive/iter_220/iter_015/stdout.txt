```python
def _try_build_c2_rule(pairs: list) -> dict | None:
    rule: dict = {}
    for a, b in pairs:
        rot_a, rot_b = _rotate_c2(a), _rotate_c2(b)
        for src, dst in [(a, b), (b, a), (rot_a, rot_b), (rot_b, rot_a)]:
            if src in rule:
                if rule[src] != dst:
                    return None
            else:
                rule[src] = dst
    return rule
```

### How `pairs` is structured

Each element in `pairs` is a **tuple `(a, b)`** of two integers in the range **1–127**.

- `a` and `b` are **hex-neighbourhood state encodings** (7-bit values, one bit per cell in the 7-cell hex pattern: bit6=center, bit5=E, …, bit0=NE).
- A single pair `(a, b)` is not just a single rule mapping — it generates **4 C2-symmetric mappings**:
  1. `(a → b)`        direct mapping
  2. `(b → a)`        reversed mapping
  3. `(rot_a → rot_b)`  180° C2 rotation of the first
  4. `(rot_b → rot_a)`  180° C2 rotation of the second

The helper `_rotate_c2(state)` rotates a 7-bit hex state by 180° (equivalent to three 60° CW rotations via `_rotate60`).

### How the rule is built

1. **Iterate each pair** `(a, b)` in the input list.
2. **Compute `rot_a` and `rot_b`** — the 180° C2-rotated versions.
3. **Try all 4 ordered mappings** — if a mapping's source key is already in `rule`, it must map to the same destination; otherwise a **conflict** is detected and the function returns `None` (rejecting the rule).
4. If no conflict is found after all pairs, the fully populated `rule` dict is returned.

This is called by `generate_random_c2_rule`, which randomly samples `k` pairs (where `k ∈ {2, 3, 4}`) and retries until a conflict-free C2-symmetric rule is found.
