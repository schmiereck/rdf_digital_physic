## 1. Population Initialization — **Fully Random** (No Warm-Start)

The initial population is generated by `generate_population()` (lines 118–124), which calls `generate_random_c2_rule(rng)` from `evolution.py` for every individual. There is **no warm-start, no seed rules, no prior knowledge** baked in — the population is 100% random.

**How a random C2-symmetric rule is generated** (`evolution.py`, `generate_random_c2_rule`, line 59):

1. It picks **k = 2–4 random state-pairs** `(a, b)` from the 127 possible states (states 1–127; state 0 = the center-neighbourhood)
2. Each pair `(a, b)` means: *"the 7-cell neighbourhood encoding `a` should evolve into state `b`"* (same for `b → a`)
3. **C2 symmetry is enforced** by applying a 180° rotation (`_rotate_c2`) to each pair. For every `(a, b)`, the code also enforces `(rotate180(a), rotate180(b))` and the two reversed variants `(b, a)` and `(rotate180(b), rotate180(a))`. This gives up to 4 constraint pairs per seed-pair.
4. It tries up to **10,000 random pair-sets** until it finds one that produces a **non-conflicting** rule table (no state maps to two different values)
5. The result is a sparse rule dict, which is then converted to a full 128-entry **chromosome** of 0/1 bits (`rule_dict_to_chromosome`)

So the initial 100 individuals are all **unrelated random C2-symmetric rules** with 2–4 constraints each.

## 2. Mutation — **Swap Mutation** on the Chromosome

Mutation is performed by `swap_mutate()` (lines 139–146):

```python
def swap_mutate(chrom: np.ndarray, num_swaps: int, rng: random.Random) -> np.ndarray:
    out = chrom.copy()
    n   = len(out)                    # 128 (LUT_SIZE)
    for _ in range(num_swaps):
        i, j     = rng.sample(range(n), 2)   # pick 2 distinct indices
        out[i], out[j] = out[j], out[i]       # swap their 0/1 values
    return out
```

### Caveats / observations:

- The mutation operates at the **chromosome level** (individual bits in the lookup table), not at the **rule-constraint level**. A single swap can arbitrarily add or remove a single rule entry, potentially breaking C2 symmetry since it doesn't coordinate all 4 symmetric positions. This means some children may have **non-C2-symmetric rules**.
- The elite preservation (10 %) with very light mutation (1 swap) means **very little diversity** is injected per generation — the search is mostly driven by selection pressure on the top 10%.
