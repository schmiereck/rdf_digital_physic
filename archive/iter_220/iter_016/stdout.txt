## 3. The Fitness Functions

### Option A: `LeakySubLightFitness` (default, `--strict` not set)

Found in `src/leaky_fitness.py`. This is a **"soft" bit-conservation** fitness:

**Formula:**
```
conservation_factor_at_checkpoint = 1.0                    if bit_count == initial_bits
                                  = min(bits, init) / max(bits, init)  otherwise

total_conservation_score = mean(conservation_factors across all checkpoints)

base_fitness = net_displacement  (Euclidean distance from initial CoM → final CoM)

final_fitness = base_fitness * total_conservation_score
```

**Velocity gate:** If the mean speed across all 200 steps ≥ 0.9 cells/step → fitness = 0.0

**Checkpoints:** Bits are sampled at steps 50, 100, and 150. Rules that lose or gain particles get a fractional penalty proportional to how far they deviate from the original 3-bit mass.

### Option B: `SubLightFitness` (with `--strict`, from `src/fitness_functions.py`)

This is a **hard-gated** fitness designed specifically to find *sub-light-speed* (v < c) periodic gliders:

**Hard gates (return fitness = 0 if any fail):**
1. **Bit conservation**: Final bits must equal 3 (the L-tromino seed size). With `strict_bit_conservation=True`, bits must equal 3 at *every* step.
2. **Displacement > 0**: The particle must move.
3. **Velocity gate**: Mean velocity must be < 0.9 cells/step (rejects v=c gliders).
4. **Period gate**: The smallest internal period T > 1 (rejects period-1 trivial translation).

**Formula (only reached if all gates pass):**
```
period_bonus = 1.0 - 1.0 / T    (where T is the internal period)
fitness = displacement * period_bonus
```

**Displacement measurement:** Uses **unwrapped centre-of-mass** tracking with minimum-image wrap correction — measures displacement over a "late window" (steps 100→200 by default).

**Period detection:** Normalizes the particle's configuration via toroidal CoM-relative offsets, then finds the smallest repeating period k in the configuration history.

**Why this rejects v=c gliders:**
- A v=c glider has period 1 → `period_bonus = 0` → fitness = 0
- It also has velocity = 1.0 ≥ 0.9 → velocity gate rejects it
