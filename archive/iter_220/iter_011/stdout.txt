## What the Mappings Define

This is a rule for a **7-input hexagonal-neighbourhood cellular automaton** on a 2D grid. Every cell looks at itself and its 6 hex neighbours, forming a 7-bit pattern that encodes an input index from 0 to 127. The rule maps each input index to an output bit (0 = dead / off, 1 = alive / on).

### 1. The Chromosome (full LUT)

The 128-element `chromosome` array is a **truth table**: `chromosome[i]` gives the output bit when the 7-bit neighbourhood state equals `i`. The first 128 integers (0–127) are indexed in order.

For example:
- `chromosome[0] = 0` — all neighbours dead → cell dies (stays dead)
- `chromosome[1] = 0`
- `chromosome[64] = 0` — only the cell itself alive → the cell dies
- `chromosome[68] = 1` — this one is flipped (the cell stays alive when neighbours are in a specific pattern)

A value of `1` in the chromosome means that for this specific 7-bit neighbourhood configuration, the new state of the cell is **ON**.
