### Key Architectural Difference (Not Yet Exploited)

The 2D hex model uses **7 channels = 6 propagation + 1 rest-mass channel**. The rest channel is critical: it allows bits to **stay** at a cell across multiple time steps, creating persistent local interactions. When propagation bits arrive at a cell that already has a rest bit, the collision at that cell can create new bits via the non-additive weight-2+ mappings. This is the "neighborhood overlap" mechanism — the rest bit at cell P overlaps with the neighborhoods of P's adjacent cells.

The 3D FCC model uses **12 channels = all propagation, no rest channel**. Every bit at cell P must move to an adjacent cell in the next propagation step. There is no persistent local state for arriving bits to interact with. This makes all interactions transient — exactly the structural limitation identified in iter_250.

**The rest channel is the missing ingredient.** It converts transient co-located interactions into persistent neighborhood-overlap interactions.
