# Sub-Planner Task (depth 1)

Your iter_id context is `222.4`. When spawning sub-agents via run_agent, form their IDs as `222.4.1`, `222.4.2`, etc.

## Goal

Orchestrate a complete evolutionary search for a stable, sub-light speed (v<c) glider in the 2D hexagonal grid using a new, perfectly C2-symmetric 72-orbit chromosome representation and ProcessPoolExecutor for parallel execution.

Key specifications:
1. Create `src/run_evolution_exp_222.py` by designing a 72-orbit-based chromosome where 128 states are mapped to 72 unique orbit indices. Standard crossover and mutation are applied directly to the 72-bit orbit chromosome, guaranteeing 100% C2 symmetry by construction.
2. Load warm-start rules from `archive/iter_215/results/final_population.json` and convert/symmetrize them into 72-orbit chromosomes to form the initial population of size 100.
3. Evaluate fitness using:
   - Perfect per-step unwrapped CoM simulation loop.
   - DisplacementConsistencyFitness(num_windows=5, max_bit_threshold=12, max_velocity_threshold=0.9, min_velocity=0.02) from src/new_fitness.py.
4. Run for 50 generations with population size 100, elite size 10, crossover rate 0.5, and bit-flip mutation rate 0.02. Use ProcessPoolExecutor to run evaluations in parallel.
5. Output results to `archive/iter_222/results/`: champion_rule_perfect.json, evolution_summary_perfect.csv, and a GIF of the champion.
6. Verify and characterize the champion: analyze its trajectory, speed, and stability over 500 steps. Ensure it is a genuine, stable v<c glider.
