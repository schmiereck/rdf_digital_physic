## Deep Analysis

### The Core Problem (iter_248)

The fundamental finding is devastating but clear: **LUT-08's weight-1 mapping consists of 6 disjoint period-2 transpositions** (ch0↔ch3, ch1↔ch2, ch4↔ch7, ch5↔ch6, ch8↔ch11, ch9↔ch10). Because these are disjoint, when multiple bits are present at the same cell, the LUT output is the *additive superposition* of independent transpositions. Every "multi-bit glider" is just k independent single-bit particles that happen to travel in proximity but never truly interact. They fail all three coherence tests.

### Why This Happens

The `generate_symmetric_lut()` construction uses an **orbit-matching strategy** that inherently produces additive (linear) weight-1 transpositions. When two or more channels are active, the LUT simply applies each bit's independent transposition — there is no mechanism for inter-channel coupling. This is a structural consequence of the construction method, not a property of O_h symmetry itself.

### The User's Insight

"View the bits as fields that can also interact with each other. Extend the logic of the interaction."

This points to a fundamental redesign of the LUT: instead of building from independent weight-1 transpositions upward (additive), we must construct the LUT so that weight-≥2 entries create genuine inter-channel coupling — where the output for a multi-bit input is NOT the superposition of independent single-bit transitions.

### Mechanism: Non-Additive Weight-2 Interactions

In the LGCA update cycle (Collision → Streaming), bits only interact during the Collision step when they share a cell. Currently, when two bits occupy the same cell, the additive LUT sends each bit along its independent trajectory (pass-through). The key change: **modify weight-2 LUT entries so that simultaneously-arriving bits scatter into different channels than their independent transposition targets.** This creates genuine interaction: the trajectory of each bit depends on the presence of the other.

### Concrete Construction: Orbit-Pair Output Swap

The LUT is a permutation on 2^12 = 4096 states. To create non-additive weight-2 entries while preserving reversibility:
1. Take two weight-2 states from the same or different O_h orbits: {ch_i, ch_j} and {ch_k, ch_l}
2. Swap their LUT outputs: LUT[{i,j}] ↔ LUT[{k,l}]
3. Close under O_h: for each rotation R, also swap LUT[R{i,j}] ↔ LUT[R{k,l}]
4. Verify: the modified LUT remains a bijection and bit-conserving

This "LUT surgery" preserves all invariants while introducing controlled inter-channel coupling.

### Types of Interaction to Test

1. **Exchange coupling:** Swap one output channel between two transposition pairs. Example: if additive output of {0,1} is {2,3} and output of {4,5} is {6,7}, map {0,1}→{2,7} and {4,5}→{6,3} — one bit from each pair "leaks" into the other's trajectory.

2. **Binding coupling:** Redirect both output channels into channels that belong to the same velocity cycle. Example: map {0,1}→{5,6} (both bits enter the [5,6] cycle and co-propagate).

3. **Scattering coupling:** Redirect output channels to channels with different velocities than either input, creating deflection. Example: map {0,1}→{8,9} (bits redirected into slow/stationary cycles).

Each type creates different dynamics when two single-bit particles collide. The binding coupling is the most likely to create genuine bound states (multi-bit gliders where bits periodically share a cell).
