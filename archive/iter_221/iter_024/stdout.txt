### Problem

On a toroidal (wrapped) grid of size `128×128`, positions near opposite edges are artificially close. The raw center of mass can "jump" by up to 64 cells when particles cross a boundary, even though they move only a few cells in physical space. The unwrapper eliminates these artificial jumps.

### Algorithm

**1. Step 0 — Seed the unwrapped coordinates:**

```python
unwrapped_prev = [np.array(c, dtype=float) for c in raw_cell_lists[0]]
com_prev = float(np.mean(unwrapped_prev, axis=0)[0]), float(np.mean(unwrapped_prev, axis-0)[1])
```

Each active cell at step 0 starts unwrapped at its raw grid position. The initial CoM is their simple arithmetic mean.

**2. For each subsequent step `t`, find the best cell-to-cell alignment:**

```python
for pi, pc in enumerate(unwrapped_prev):
    for ci, cc in enumerate(cells_t):
        dr = (cc[0] - int(pc[0]) + GRID_SIZE // 2) % GRID_SIZE - GRID_SIZE // 2
        dc = (cc[1] - int(pc[1]) + GRID_SIZE // 2) % GRID_SIZE - GRID_SIZE // 2
```

This is the classic **modulo-distance** formula:
- `cc[i] - pc[i]` gives the raw difference (can be −127…+127).
- Adding `GRID_SIZE // 2` (i.e., 64) and taking `% GRID_SIZE` wraps it into `[0, 127)`.
- Subtracting `GRID_SIZE // 2` shifts it into `[−63, 64]`.

So `dr` and `dc` are the **shortest toroidal distance** between a previously-unwrapped cell and a current raw cell, always in the range **−63 to +64**. This correctly handles wrapping: e.g., a cell that moved from row 127 to row 0 gets `dr = +1`, not `dr = −127`.

The best `(prev_cell, current_cell)` pair (minimizing `dr² + dc²`) is chosen as an **anchor**.

**3. Compute offsets of all current cells from the anchor, then shift:**

```python
anchor_unwrapped = unwrapped_prev[p_idx] + np.array([dr_t, dc_t])

for cc in cells_t:
    dr_r = (cc[0] - anchor_grid[0] + GRID_SIZE // 2) % GRID_SIZE - GRID_SIZE // 2

```

Every cell's offset from the anchor is computed in wrapped form (again using the mod formula), then the entire set is shifted by `anchor_unwrapped` — which is the anchor cell's **continuous** (unwrapped) position. This preserves the relative structure of the pattern while placing it in global continuous coordinates.

**4. Compute the new CoM:**


### Why It Works

| Aspect | Detail |
|---|---|
| **Anchor alignment** | Finds the closest previous cell → current cell pair via toroidal distance, ensuring the best local match. |
| **Toroidal distance** | `(a - b + N//2) % N - N//2` always returns the shortest signed distance in `[−N/2, N/2]`. |
| **Consistency** | All cells at step `t` are placed relative to the anchor's known unwrapped position, so the whole pattern moves coherently. |
| **Handles disappearing cells** | If step `t` has no active cells, it emits `(0.0, 0.0)`. |
| **Iterative** | Each step builds on the previous step's fully unwrapped positions, accumulating drift naturally. |

The net result is a smooth, continuous CoM trajectory where a glider moving diagonally across the toroidal boundary doesn't show a 128-cell jump — instead it continues incrementally.
