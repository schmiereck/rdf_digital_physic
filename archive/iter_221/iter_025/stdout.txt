```python
def com_and_bits(g):
    rows, cols = np.where(g > 0)
    if len(rows) == 0:
        return (0.0, 0.0), 0
    return (float(np.mean(rows)), float(np.mean(cols))), int(g.sum())
```

This is a nested function inside `simulate_with_history` that:
- Computes the **center of mass** (`com`) of active cells in the grid (mean of row and column indices)
- Counts the **number of active bits** (`bit_count`) in the grid
- Returns both values as a tuple: `((com_row, com_col), bit_count)`
