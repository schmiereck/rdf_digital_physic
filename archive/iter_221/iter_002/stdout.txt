### `_detect_period` (static, lines ~213–223)

```python
@staticmethod
def _detect_period(configs: list[frozenset], max_period: int) -> int:
    """Smallest k in [1, max_period] with configs[i] == configs[i+k]
    for every valid i.  Returns 0 if no such period."""
    n = len(configs)
    if n < 2:
        return 0
    upper = min(max_period, n - 1)
    for k in range(1, upper + 1):
        if all(configs[i] == configs[i + k] for i in range(n - k)):
            return k
    return 0
```

### `evaluate` (lines ~228–330) — the core method

**Formula**:

fitness = displacement * (1 - 1/period)

**Gates / Rejection conditions** (all return `fitness = 0.0`):
| Gate | Reason |

| `period <= 1` | `"period_too_short"` |

**Pipeline**:
1. Simulate the full `simulation_steps` with unwrapped COM tracking (toroidal-aware).
2. Collect normalised grid configs during the period-detection window.
3. Compute late-window displacement between `window_start` and `window_end`.
4. Detect internal period from the config fingerprint (translation-normalised frozenset).
5. Apply the formula: `fitness = displacement * (1.0 - 1.0/period)`.
