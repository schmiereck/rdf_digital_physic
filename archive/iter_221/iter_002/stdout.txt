## 1. How Are the Rules Initialized? (From Scratch)

The GA **always starts from scratch**. In `main()`, line 199:


This calls `generate_population()` (line 146), which creates random C2-symmetric rules:

```python
def generate_population(size: int, rng: random.Random) -> list[np.ndarray]:
    pop: list[np.ndarray] = []
    while len(pop) < size:
        rule = generate_random_c2_rule(rng)       # random C2 rule from scratch
        pop.append(rule_dict_to_chromosome(rule))  # convert to chromosome
    return pop[:size]
```

Each chromosome is a **128-element `uint8` array** of bits. Each bit `chrom[s]` controls whether the LUT entry `s` has its center-bit (bit 6) flipped relative to the C2-symmetric default (`s | (s >> 6)`).

### Option B: Command-line argument + smarter seeding

For a more polished approach, you could also support seeding just the top-N warm-start individuals into a mixed population:

```python
WARM_START_PATH = os.environ.get("WARM_START_PATH", "")
WARM_START_TOP_K = int(os.environ.get("WARM_START_TOP_K", "0"))  # 0 = use all

if WARM_START_PATH:
    with open(WARM_START_PATH) as f:
        ws_data = json.load(f)
    entries = ws_data.get("population", ws_data)
    warm_start_pop = [np.array(e["chromosome"], dtype=np.uint8) for e in entries]
    
    if WARM_START_TOP_K and WARM_START_TOP_K < len(warm_start_pop):
        # Evaluate warm-start individuals and keep the top-K
        print(f"Evaluating {len(warm_start_pop)} warm-start candidates to select top {WARM_START_TOP_K} ...")
        ws_scores = evaluate_population(warm_start_pop)
        top_order = sorted(range(len(ws_scores)), key=lambda i: ws_scores[i], reverse=True)
        population = [warm_start_pop[i].copy() for i in top_order[:WARM_START_TOP_K]]
        # Fill the rest with random individuals
        remaining = POPULATION_SIZE - len(population)
        population.extend(generate_population(remaining, rng))
        print(f"  Selected top {WARM_START_TOP_K} + {remaining} random = {len(population)}")
```
