## `new_fitness.py` — Structure & Imports (first 50 lines)

```python
from __future__ import annotations
import math
from typing import Any
import numpy as np

class DisplacementConsistencyFitness:
    """Fitness function that rewards consistent, directional motion.

    Core formula:
        base_fitness = mean_velocity_magnitude / (1 + std_dev_velocity_magnitudes)

    Strategy: Divides simulation into `num_windows` equal-duration windows.
    For each window, computes a velocity vector from center-of-mass displacement.
    Then penalizes objects whose velocity magnitudes fluctuate (drifters),
    while rewarding objects with stable, directional motion (true gliders).
    """
```

The class takes `sim_history` (list of dicts with `step`, `com`, `bit_count`) and computes fitness by measuring velocity consistency across windows — effectively filtering out "drifter" exploits that game simple displacement metrics.
