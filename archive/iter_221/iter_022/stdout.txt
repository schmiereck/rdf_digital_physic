## Finding: History is generated at EVERY step, not just at checkpoints

### Key Finding

In the main evolution loop (`run_evolution_exp_220.py`), the `simulate_with_history()` function records COM at **every single step** — both the initial state (step 0) AND every step from 1 to 500. There is no checkpoint-based subsampling.

---

### Relevant Code — `src/run_evolution_exp_220.py` (lines 76–97)

```python
def simulate_with_history(rule_dict: dict) -> list:
    lut  = rule_dict_to_lut(rule_dict)
    grid = np.zeros((GRID_SIZE, GRID_SIZE), dtype=np.uint8)
    grid[63, 63] = 1
    grid[64, 63] = 1
    grid[64, 64] = 1

    def com_and_bits(g):
        rows, cols = np.where(g > 0)
        if len(rows) == 0:
            return (0.0, 0.0), 0
        return (float(np.mean(rows)), float(np.mean(cols))), int(g.sum())

    c0, b0 = com_and_bits(grid)
    hist = [{"step": 0, "com": c0, "bit_count": b0}]   # ← step 0 recorded
    for t in range(1, STEPS + 1):                       # ← loop 1..500
        grid = step_grid(grid, lut)
        c, b = com_and_bits(grid)
        hist.append({"step": t, "com": c, "bit_count": b})  # ← EVERY step appended
    return hist
```

With `STEPS = 500`, this produces **501 history entries per evaluation**.

### The fitness evaluator uses this full history

```python
_fitness_fn = DisplacementConsistencyFitness(num_windows=5)
```

### Summary

| File | What it records | Frequency |
|---|---|---|
| `run_evolution_exp_220.py` `simulate_with_history()` | `{"step", "com", "bit_count"}` | **Every step** (0..500 = 501 entries) |
| `run_champion_eval.py` `simulate_with_history()` | Same | **Every step** (0..steps) |
| `src/fitness_functions.py` `SubLightFitness.evaluate()` | Internal `com_history` list | **Every step** (used for window lookups) |
| `src/new_fitness.py` `DisplacementConsistencyFitness.__call__()` | Consumes full history | Iterates all entries for unwrapping |

**Answer: History records COM at every single step, not just at checkpoints (e.g., every 50 or 100 steps).** With 500-step simulations and a population of 100 evaluated per generation, that's 50,100 COM recordings per generation. The `DisplacementConsistencyFitness` then iterates all of those entries to unwrap COMs and compute per-window velocity vectors.
