### 4. Mutation — **Swap Mutation**
```python
def swap_mutate(chrom: np.ndarray, num_swaps: int, rng: random.Random) -> np.ndarray:
    out = chrom.copy()
    n   = len(out)
    for _ in range(num_swaps):
        i, j     = rng.sample(range(n), 2)
        out[i], out[j] = out[j], out[i]
    return out
```
- Number of swaps = `round(MUTATION_RATE * LUT_SIZE) = round(0.01 * 128) = 1` swap per child.
- Two random bit positions are swapped.

### 5. Generational Loop (generational GA)
```python
for gen in range(1, GENERATIONS + 1):
    elites   = select_top_k(population, scores, ELITE_SIZE)   # Select top 10
    next_pop = [e.copy() for e in elites]                     # Elites pass through
    while len(next_pop) < POPULATION_SIZE:
        parent = rng.choice(elites)                           # Random elite parent
        child  = swap_mutate(parent, num_swaps, rng)          # Mutate
        next_pop.append(child)                                # Fill remainder
    population = next_pop
```
