### Velocity Calculation (lines 325–352)

For each of the `num_windows` windows in the simulation history:

1. **Windowing**: The global simulation history is split into time windows. For each window, the first and last entries within that window's step range are found.
2. **Displacement**: `dx` and `dy` are computed as the difference in center-of-mass (COM) positions between the last and first entries.
3. **Per-window velocity magnitude**:
   ```python
   velocity_mag = math.sqrt(dx*dx + dy*dy)
   if window_steps > 0:
       velocity_mag = velocity_mag / window_steps   # pixels per step
       dx = dx / window_steps
       dy = dy / window_steps
   ```
   This gives a velocity in **units per step**, averaged over each window.

4. **Mean directional drift** (lines 355–361): The per-window velocity *vectors* `(dx, dy)` are averaged across all windows:
   ```python
   mean_dx = sum(v[0] for v in window_velocity_vectors) / self.num_windows
   mean_dy = sum(v[1] for v in window_velocity_vectors) / self.num_windows
   mean_velocity_magnitude = math.sqrt(mean_dx*mean_dx + mean_dy*mean_dy)
   ```
   This captures the **net directional drift** — i.e., whether the organism moves predominantly in one direction.

### `max_velocity_threshold` Check (lines 363–364)

if self.max_velocity_threshold is not None and mean_velocity_magnitude >= self.max_velocity_threshold:
