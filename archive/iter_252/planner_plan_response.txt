Based on my thorough analysis of the current state, here is my assessment and plan:

## Analysis

The project is at a critical juncture in Phase 7.1. Three consecutive iterations (248, 250, 251) have established:

1. **All O_h-symmetric single-cell collision rules produce only non-interacting composites** (iter_248). The LUT-08 "glider" was shattered — its 4 bits travel on parallel paths without sharing cells; binding energy = 0.0.

2. **The 2D hex v=0.469c glider IS genuine** (iter_250). All 3 constituent bits annihilate when isolated. Only the full L-tromino survives. The binding mechanism is **cooperative survival through neighborhood-overlap bit creation**.

3. **13-channel cooperative trapping + rest channel produces stationary oscillators** (iter_251). The rest channel anchors prop bits into orbiting patterns. Cross-orbit C↔E weight-2 mapping is **mathematically impossible** under O_h (non-conjugate stabilizer subgroups).

**The fundamental diagnosis:** Under O_h symmetry, all 12 directional channels form a single orbit. Weight-1 states must all follow the same cycle type (up to rotation). This makes "conditional death" — the core of the 2D hex cooperative survival mechanism — structurally impossible. A bit that survives alone cannot be made to "die" in a way that creates binding energy.

**The strategic opening:** The FCC lattice consists of stacked hexagonal planes perpendicular to [111]. Each cell has 6 in-plane neighbors (forming a hex lattice) and 6 out-of-plane neighbors. The proven 2D hex glider rule can be directly embedded into these hex planes. This requires reducing symmetry from O_h to C3v (the symmetry of the [111] plane within O_h), but this is physically justified: the 2D hex mechanism is the ONLY confirmed binding mechanism, and C3v is the minimum symmetry group that supports it in 3D.

## Hypothesis

When the proven 2D hex glider rule (`champion_rule_perfect` from iter_222) is embedded into a [111] hex plane of the 3D FCC lattice as a factorized 13-channel LGCA (6 in-plane channels + 1 center channel following the 2D hex rule; 6 inter-plane channels following an identity mapping), the resulting system supports a genuine multi-bit bound glider with binding energy > 0 that propagates within the [111] hex plane at v ≈ 0.469c. Furthermore, introducing controlled non-factorized coupling between in-plane and inter-plane channels can produce 3D binding (bits spanning multiple planes) while preserving glider stability at coupling strengths below a critical threshold.

## Falsification Criteria

- **F1 (Embedding Failure):** The 2D hex glider does not survive embedding into the 3D FCC lattice — no stable propagation for 200+ steps from the L-tromino seed on the [111] plane.
- **F2 (Composite Trap):** The embedded glider propagates but fails the Single-Bit Decomposition Test — isolated constituent bits survive independently, proving it's a non-interacting composite.
- **F3 (LUT Construction Failure):** The 13-channel factorized LUT cannot be constructed to be simultaneously bijective, bit-conserving, and compatible with the 2D hex rule on in-plane+center channels.
- **F4 (No 3D Binding):** For all tested coupling strengths (0.0 to 1.0 in 0.1 increments), either the glider is destroyed (disperses within 200 steps) or no 3D binding emerges (no configuration with bits on 2+ planes passes the Three-Test Coherence Protocol over 500 LUT variants × 50 seed configurations).

  - 6 in-plane channels map to 2D hex channels
  - 1 center channel (shared with 2D hex rule)
  - 6 inter-plane channels (3 above + 3 below the [111] plane)

- Verify: bijectivity audit, bit conservation audit, C3v symmetry check

- **Positive control:** Run 2D hex rule on standalone 2D hex grid (should produce genuine glider per iter_250)
- Place L-tromino seed on [111] plane, run 300 steps
- If glider survives: apply Single-Bit Decomposition Test (isolate each of 3 seed bits, run 50 steps, check survival)
- **Output:** `src/fcc_engine_embed.py`, `src/test_embedded_glider.py`, test results

### Sub-goal 252.3 — Inter-Plane Coupling Search (High complexity, conditional on 252.2 success)
- Design coupled LUTs: `LUT_13ch(s) = (1-α)·factorized(s) + α·coupled(s)` where α controls coupling strength
  - At α=0: pure factorized (2D hex glider works)
  - At α=1: fully coupled (maximum inter-plane interaction)
  - The coupled component modifies the output based on inter-plane channel states
- Sweep α from 0.0 to 1.0 in 0.1 increments
- At each α: run 500 LUT variants × 50 seed configurations (including multi-plane seeds) for 300 steps
- Apply Three-Test Coherence Protocol to any survivors with displacement > 50
- Search for 3D gliders (bits spanning 2+ hex planes)
- **Output:** `src/interplane_coupling.py`, coupling sweep results

### Sub-goal 252.4 — O_h Covariance Test (Medium complexity, conditional on 252.3 success)

- If glider fails O_h covariance: this is EXPECTED (the rule has only C3v symmetry). Document as a known limitation.
- Test whether the glider survives C3v rotations (the natural symmetry of the [111] embedding)
- **Output:** Covariance test results, symmetry characterization
