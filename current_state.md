Phase: Phase 3: Die 2D-Hex-Kollision (Streuung)

## 1. Goal
Demonstrate that complex physical phenomena can emerge from minimal, local, reversible rules on a discrete, symmetric lattice.

## 2. Confirmed Findings
- **Rule Existence (1-bit):** 33 non-trivial, reversible, bit-conserving rules exist for a 1D, 3-bit neighborhood (iter_009).
- **v=c Gliders (1-bit):** 22 of the 33 1-bit rules produce stable gliders at the speed of light (iter_010).
- **Rule Existence (2-bit):** Non-trivial, reversible, bit-conserving rules exist for a 1D, 3-neighborhood, 2-bit/cell lattice (iter_011).
- **v=0 Oscillators (2-bit):** A minimal 2-bit/cell rule produces a stable, stationary, period-2 oscillation (iter_012).
- **v < c Particles (2-bit):** A hybrid rule can produce a stable single-cell glider with v=c/2 (iter_013).
- **Composite Particles:** A rule can be constructed to make a two-cell particle propagate stably with v=c/2 (iter_014).

## 3. Current Best Result
- **Fastest Particle:** v=c (1.0 cells/step) using a 1-bit rule (iter_010).
- **"Massive" Particle:** v=c/2 (0.5 cells/step) using single-cell or two-cell 2-bit rules (iter_013, iter_014).

## 4. In Progress
- **iter_015:** Verifying the existence of non-trivial, reversible, bit-conserving rules for a 2D hexagonal lattice.

## 5. Open Questions
- Does a 2D hexagonal topology support stable, propagating patterns (gliders)?
- Can a simple 1D glider rule be embedded or extended to create linear motion in 2D?
- What is the minimal set of rule mappings required to produce a collision with a non-trivial scattering angle?
- How do the symmetries of the hexagonal grid constrain possible interactions?
