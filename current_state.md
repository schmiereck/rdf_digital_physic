Phase: Phase 3: Die 2D-Hex-Kollision (BLOCKED)

## Confirmed
- 1D, 1-bit/cell rules support v=c gliders (iter_010).
- 1D, 2-bit/cell rules support v<c composite particles (v=0, v=c/2), achieving the Phase 2 milestone (iter_014).
- A hand-crafted, reversible, bit-conserving rule can produce a stable 2D glider (the "arrowhead", iter_024).
- A symmetric swap-based update scheduler can produce stable, localized 2D oscillators (iter_020).

## Refuted
- **Fundamental Block:** The hand-crafted "arrowhead" glider rule lacks the rotational symmetry of the hexagonal lattice, making it unsuitable for physics experiments. A rotated seed pattern under this rule leads to chaotic growth (iter_028).
- Simple, unconditional local rules in 2D (e.g., bit-swaps) produce trivial global grid shifts, not localized particles (iter_017).
- Simple bit patterns are not stationary targets for the non-symmetric arrowhead rule (iter_026, iter_027).

## Current Best Result
The "arrowhead" glider (iter_024) is the only known stable, non-trivial 2D particle, but its governing rule is fundamentally flawed (non-symmetric).

## In Progress
- **iter_029:** Testing a new, programmatically *symmetrized* rule to overcome the rotational symmetry failure.

## Open Questions
1. Can a programmatically symmetrized rule support stable, non-trivial gliders?
2. If a symmetric rule supports a glider, does a rotated seed produce a correctly rotated glider?
3. Can a stationary, stable particle exist under a fully symmetric rule?
4. How do gliders generated by a symmetric rule interact during a head-on collision?
